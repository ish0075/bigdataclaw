# Property Acquisition Project

This project encompasses all activities related to sourcing, analyzing, and acquiring commercial real estate assets.

## Objectives

1. **Pipeline**: Maintain 50+ qualified opportunities
2. **Velocity**: 90 days from intro to LOI
3. **Returns**: 15% minimum IRR
4. **Coverage**: 100% of target markets

## Phases

### Phase 1: Sourcing
- Hot money monitoring
- Builder/developer research
- Transaction surveillance
- Market scanning

### Phase 2: Qualification
- Initial screening
- Market analysis
- Preliminary underwriting
- Priority scoring

### Phase 3: Deep Diligence
- Full market report
- Property valuation
- Capital source alignment
- Relationship mapping

### Phase 4: Execution
- LOI preparation
- Negotiation support
- Due diligence
- Closing coordination

## Key Workflows

### Opportunity Flow
```
Signal Detected → Research → Score → Brief Created → 
CTO Review → CMO Assignment → Outreach → 
Meeting → LOI → DD → Close
```

### Research Request Flow
```
Request Submitted → Market Researcher Assigned → 
48hr Turnaround → Review → Delivery → Archive
```

## Success Criteria

- 20+ new opportunities sourced per week
- 50+ active pipeline opportunities
- 10% LOI to close conversion
- < 90 days average deal cycle
