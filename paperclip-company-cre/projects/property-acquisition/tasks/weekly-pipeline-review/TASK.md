# Weekly Pipeline Review

## Objective

Review the full opportunity pipeline, prioritize deals, and identify resource needs.

## Agenda

1. **Pipeline Status** (15 min)
   - Total pipeline value
   - New opportunities this week
   - Stage breakdown
   - Conversion metrics

2. **Deal Reviews** (30 min)
   - Top 5 priority deals
   - Go/no-go decisions needed
   - Resource requirements
   - Timeline assessment

3. **Team Capacity** (10 min)
   - Workload distribution
   - Bottlenecks
   - Hiring needs

4. **Action Items** (5 min)
   - Next week priorities
   - Resource allocation
   - Escalations

## Output

- Pipeline summary report
- Prioritized action list
- Resource requests (if any)

## Frequency

Every Monday at 10:00 AM ET

## Attendees

- CTO (lead)
- CMO
- CEO (if strategic decisions needed)
