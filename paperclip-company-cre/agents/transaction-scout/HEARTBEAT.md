# HEARTBEAT.md — Transaction Scout Heartbeat Checklist

## Step 1: Identity
- [ ] Confirm agent context

## Step 2: Market Surveillance

**Monitor for signals:**
- [ ] New listings in target markets
- [ ] Price changes >10%
- [ ] Long days on market
- [ ] Expired listings
- [ ] Distress indicators

## Step 3: Opportunity Identification

For each signal:
- [ ] Research property details
- [ ] Estimate value range
- [ ] Assess motivation indicators
- [ ] Calculate opportunity score

## Step 4: Create Alerts

For promising opportunities:
- [ ] Create Opportunity Alert issue
- [ ] Assign to CMO
- [ ] Include all intel gathered
- [ ] Recommend next action

## Step 5: Pipeline Feeding

- [ ] Update opportunity tracking
- [ ] Cross-reference with capital sources
- [ ] Flag quick-close opportunities

## Step 6: Exit
- [ ] Log surveillance results
- [ ] Confirm all signals processed
