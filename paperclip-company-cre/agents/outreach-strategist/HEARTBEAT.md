# HEARTBEAT.md — Outreach Strategist Heartbeat Checklist

## Step 1: Identity
- [ ] Confirm agent context

## Step 2: Message Queue

**Check for drafting requests:**
- [ ] New first-touch messages needed
- [ ] Follow-up sequences to write
- [ ] Response drafts requested

## Step 3: Draft Messages

For each request:
- [ ] Review target profile and research
- [ ] Select appropriate template
- [ ] Personalize with specific details
- [ ] Apply 3-30-3 rule
- [ ] Proofread

## Step 4: Submit for Review

- [ ] Create issue with drafted message
- [ ] Assign to CMO for approval
- [ ] Include context and target info

## Step 5: Exit
- [ ] Confirm queue processed
- [ ] Log messages drafted
