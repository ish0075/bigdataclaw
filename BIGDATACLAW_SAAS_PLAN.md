## 🛠️ TECHNICAL ARCHITECTURE

### **Stack**
- **Frontend**: React + TailwindCSS + Recharts
- **State**: Zustand (persist to localStorage/IndexedDB)
- **Backend**: Python FastAPI (optional for cloud sync)
- **Database**: SQLite (local) / PostgreSQL (cloud)
- **Auth**: Supabase Auth or Auth0
- **Payments**: Stripe

### **Data Flow**
```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Commercial  │     │   Unified    │     │  Residential │
│   Database   │────▶│   Frontend   │◀────│   Database   │
│  (DBeaver)   │     │   (React)    │     │   (CSV/MLS)  │
└──────────────┘     └──────────────┘     └──────────────┘
                            │
                            ▼
                     ┌──────────────┐
                     │  Local Store │
                     │ (IndexedDB)  │
                     └──────────────┘
```
