## CONTACT STRATEGY

### Step 1: Verbal TS Confirmation (Priority)

**Best Approach**: Site visit to Allanburg TS area

**Script**:
```
"Hi, I'm assessing a site for potential industrial development. 
I can see you have 230kV infrastructure here. Can you confirm 
if this transmission circuit is currently energized and operational?"

Follow-up: "Would you happen to know if there's available capacity 
in this corridor for a 200 MW industrial load?"
```

**What to Record**:
- Date and time of conversation
- General location (transmission tower number if visible)
- Confirmation that line is "energized and operational"
- Any comments about capacity or load availability

"I'd like to initiate a preliminary interconnection inquiry for
