## 🚀 HOW TO ACTIVATE

### Step 1: Install Dependencies (You Run)
```bash
cd ~/bigdataclaw

# Install Remotion
npm install remotion @remotion/cli @remotion/player

# Install FFmpeg
sudo apt install ffmpeg  # Linux
brew install ffmpeg      # Mac

# Install ngrok
npm install -g ngrok
ngrok config add-authtoken YOUR_TOKEN

# Install other deps
npm install framer-motion gsap puppeteer archiver
```

### Step 2: Register Agents in Paperclip
Upload these JSON files to your Paperclip company:
- `paperclip_agents/video_team/video_director.json`
- `paperclip_agents/video_team/remotion_developer.json`
- `paperclip_agents/video_team/screen_recorder.json`
- `paperclip_agents/video_team/localhost_bridge.json`
- `paperclip_agents/video_team/file_system_manager.json`
